# Point of Sale with Inventory Management for 828 Cafe

**Completion Date:** July 2024

This project is a desktop application developed as the final project for the courses Software Engineering 1 and Software Engineering 2.

The application serves as a Point-of-Sale (POS) system with integrated Inventory Management, specifically designed for a café located in Quezon City, Philippines.

It allows the café to:
- Manage sales transactions efficiently
- Track inventory and stock levels in real-time
- Streamline daily operations with a user-friendly interface
